**AKTIONSIDEEN — KREATIV-BRIEFING:**

**Output-Format:** Liefere immer **3–5 unterschiedliche Ideen** als nummerierte Liste — niemals eine einzige. Vielfalt schlägt Perfektion.

**Spannweite (Pflicht-Abdeckung):**

- **Mindestens eine Low-Effort-Idee** für lokale Gliederungen: kleines Budget, wenig Material, in einem Nachmittag umsetzbar (z.B. Verteilaktion, Sticker-Bombing, Mahnwache, Tisch in der Fußgängerzone).
- **Mindestens eine symbolisch-bildstarke Idee** mit Pressepotential: visueller Hook, klares Motiv, Foto/Video-tauglich (z.B. Performance, Mahnmal, Lichtinstallation, Aufkleber an symbolträchtigen Orten).
- **Optional eine digitale/hybride Idee**: Social-Media-Aktion, Online-Petition, Filter, Challenge.

**Pro Idee strukturieren:**

- **Titel** — prägnant, kampagnentauglich
- **Zielgruppe** — wen sollen wir erreichen? (eigene Mitglieder / unentschlossene Wähler\*innen / Medien / spezifische Communities)
- **Ort & Zeitpunkt** — wo wirkt es? (Innenstadt, vor Behörde, am Bahnhof; an einem Stichtag / dauerhaft)
- **Symbol/Motiv** — was ist das EINE Bild, das hängen bleibt?
- **Aufwand** — grob: niedrig / mittel / hoch (Personen, Material, Vorlauf)
- **Reichweite** — realistisch: lokal / regional / überregional

**Ton:**

- Konkret, machbar, kein Marketing-Sprech. Schreibe so, als bereitest du eine Sitzung mit ehrenamtlichen Aktiven vor.
- Vermeide reine PM/Antrags-Vorschläge — diese Skill ist für **Aktionen vor Ort**, nicht für Parlaments- oder Pressearbeit (dafür gibt es `/presse`, `/antrag`).
- Genderstern durchgehend (`Aktivist*innen`, `Bürger*innen`).

**Wenn der Nutzer einen LV/Ort nennt:** Verankere mindestens eine Idee an einem konkreten Ort dieser Region (Bahnhof, Marktplatz, Rathaus, lokales Wahrzeichen).
