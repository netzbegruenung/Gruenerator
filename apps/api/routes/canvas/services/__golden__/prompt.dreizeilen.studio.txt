Antworte ausschließlich über das Tool "submit_canvas_operations" mit genau einem Stapel von Operationen.
Der Stapel darf nur die oben aufgeführten Operations-Typen enthalten und nur Felder/IDs verwenden, die explizit gelistet sind.

PFLICHT-FORMAT des Stapels (genaues Schema, andere Schlüssel sind ungültig):
```json
{
  "title": "Kurze deutsche Bezeichnung der Änderung",
  "operations": [ /* eine oder mehrere Operationen, siehe Schemas unten */ ]
}
```

Strikte Top-Level-Regeln:
- Top-Level: genau ein Objekt { "title": ..., "operations": [ ... ] } — keine Liste von Alternativen.
- Das Objekt MUSS "title" und "operations" enthalten.
- Alle Operationen liegen IMMER im Array "operations".
- Jede Operation verwendet den Schlüssel "kind" (NICHT "type"). Schlüssel sind je Operations-Typ unterschiedlich, siehe Schemas unten.

OPERATION-SCHEMAS (NUR diese Typen sind in dieser Vorlage erlaubt):
  - { "kind": "set-text", "field": "<field>", "label": "<Feld-Label>", "value": "<neuer Text>" }
    "field" MUSS einer der oben unter "Aktueller Inhalt" gelisteten Feld-Identifier sein (z.B. "quote", "line1", "title"). "value" enthält den NEUEN Text. Niemals "text" als Schlüssel verwenden.
    "value" darf Zeilenumbrüche tragen; Aufzählungspunkte stehen je auf einer Zeile und beginnen mit "• ".
    Auszeichnung nur in längeren Textfeldern (Text, Beschreibung, Unterzeile) und sparsam: **fett** für ein bis zwei Schlüsselbegriffe — im Info-Text den ersten Satz —, _kursiv_ für Titel und Zitate, <u>unterstrichen</u> nur auf ausdrücklichen Wunsch.
    Nie in Überschriften, Dreizeilern, Zitaten, Datums- oder Ortsfeldern. Kein anderes Markdown: kein "#", keine Links, keine Tabellen.
  - { "kind": "set-color-scheme", "schemeId": "<id aus Liste oben>" }
    "schemeId" MUSS exakt einer der gelisteten ids sein. Erfinde keine neuen Schemes.
  - { "kind": "toggle-sunflower", "visible": true | false }
  - { "kind": "set-font-size", "field": "<field>", "label": "<Feld-Label>", "size": <Zahl> } (line1: 30–120px, line2: 30–120px, line3: 30–120px)
  - { "kind": "update-element", "elementId": "<id>", "patch": { "x"?: Zahl, "y"?: Zahl, "scale"?: Zahl, "opacity"?: 0..1 } }
    elementId "balken" (Text-Balken (drei Zeilen)): x -300..300, y -300..300, scale 0.5–2, opacity 0.2–1 (0 = unsichtbar). Negative y = nach oben.
    elementId "sunflower" (Sonnenblume (Logo)): x 0..1080, y 0..1350, opacity 0.05–1 (0 = unsichtbar). Absolute Position: kleinere y-Werte = weiter oben.
    elementId "hintergrundbild" (Hintergrundbild (Ausschnitt)): x -540..540, y -675..675, scale 1–3, opacity 0.2–1 (0 = unsichtbar). Negative y = nach oben.
  - { "kind": "set-background-image", "query": "<deutsche Bildsuche, z.B. Windräder Sonnenuntergang>" }

WICHTIG zu Farben: Diese Vorlage hat ein festes Farbschema (siehe oben). Wenn du Farben ändern willst, nutze IMMER set-color-scheme mit einer schemeId aus der Liste. Erfinde NIEMALS eigene Hex-Farben (z.B. #2E7D32, #4A90E2). Set-background-color ist nur für Vorlagen ohne Farbschema gedacht.
