# Veranstaltung

- Aufbau: `foto-oben` + `headline` (Titel, 1–2 Zeilen) + `text` (ein einladender Satz) + `datum` + `ort`.
- `datum`: weekday kurz („Do“), date „14.11.“, time „19 Uhr“ – nur aus dem Auftrag. Fehlt etwas, kein Datumskreis.
- `ort`: Name des Orts, dann Adresse – nur aus dem Auftrag.
- `position`: `oben` (der Text steht dann in der Fläche unter dem Foto).
