# Texte

- Headline: eine Aussage, 3–9 Wörter, aktivierend oder als Frage. Zeilen von 1–3 Wörtern, Umbruch an Sinngrenzen, die Kernaussage in die `akzent`-Zeile.
- `text`: das Konkrete hinter der Headline, unter 180 Zeichen.
- `==Wort==`: hebt ein einzelnes Wort oder eine kurze Wortgruppe in der Akzentfarbe hervor – in Headline-Zeilen, Absätzen und Texten. Ein bis zwei pro Slide.
- `button`: 2–4 Wörter („Jetzt Mitglied werden“, „Mitmachen“).
- Du-Ansprache, Verben statt Substantive, keine Fachbegriffe, keine Parteisprache.
- Keine URLs, Telefonnummern oder Mailadressen, wenn sie nicht wörtlich im Auftrag stehen.
