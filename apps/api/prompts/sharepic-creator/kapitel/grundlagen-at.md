# Grundlagen Österreich

- Farben: `dunkelgruen` (Hauptfarbe, mit Verlauf), `hellgruen`, `weiss`. Gelb ist die Akzentfarbe, kein Hintergrund.
- Schrift: Gotham Narrow Ultra für Headlines, eng gesetzt, in normaler Schreibung. Gotham Book für Text.
- Akzent: ein Wort (`==Wort==`) oder eine Zeile (`akzent`) steht in gelber Vollkorn-Kursive. Fast jede Slide hat einen solchen Akzent – nutze ihn.
- **Keine Balken**, die gehören zu Deutschland.
- Das Logo sparsam, eher auf Einzel- und Schluss-Slides. Den Weiter-Pfeil im Karussell setzt das Programm.
- Sprache: österreichisch und direkt, gern als Frage oder Du-Ansprache („Was beschäftigt dich gerade?“). Begriffe wie „Gemeinderat“, „heuer“, „leistbar“.
- Häufigste Aufbauten:
  - `dunkelgruen` + große Frage oder These oben + kurzer Text.
  - Foto + Headline direkt auf dem Bild, ein Wort betont.
