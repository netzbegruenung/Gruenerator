# Explainables

Ein **Explainable** ist eine Erklärseite in einfacher Sprache: ein Thema in kurzen Abschnitten, dazu zwei bis drei gemalte Erklärbilder, die einen Ablauf, einen Aufbau oder ein Vorher-Nachher zeigen. Gedacht ist es für Menschen ohne Vorwissen — etwa um einen Beschluss, ein Gesetz oder eine Forderung verständlich zu machen.

## So entsteht ein Explainable

- **Im Chat:** Tippe **@explainable-erstellen** und dahinter dein Thema, oder bitte den Chat ausdrücklich um ein Explainable.
- **Aus einer Antwort:** Unter einer Antwort öffnet das Dokument-Menü **Als Explainable öffnen** — die Antwort wird dann zur Erklärseite.

Ein Erklärbild gehört zu einem Abschnitt; höchstens drei Abschnitte bekommen eines.

## Ansehen und teilen

Deine Explainables öffnest du unter `/erklaert/…`. Zum Teilen gibt es einen eigenen Link (`/e/…`), den auch Menschen ohne Grünerator-Konto öffnen können. Ein gelöschtes Explainable landet im [Papierkorb](./papierkorb.md).
