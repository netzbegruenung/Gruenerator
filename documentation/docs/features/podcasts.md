# Podcasts

Aus einer Antwort im Chat oder im Notebook macht der Grünerator einen **kurzen Podcast**: ein Gespräch zweier KI-Stimmen. Eine Stimme moderiert und stellt die Fragen, die sich Zuhörende ohne Vorwissen stellen; die andere erklärt, mit Beispielen aus dem Alltag. Beide sprechen einfache Sprache, denn der Podcast wird gehört, nicht gelesen.

## So entsteht ein Podcast

Unter einer Antwort öffnet das Dokument-Menü **Als Podcast anhören**. Der Grünerator schreibt daraus ein Gesprächsskript — nur mit den Fakten aus der Antwort, nichts dazu erfunden — und vertont es. Eine Folge dauert etwa zwei bis fünf Minuten.

## Anhören und behalten

Der Podcast öffnet sich auf einer eigenen Player-Seite. Die MP3-Datei liegt zusätzlich als eigenes Audio in deiner **Mediathek** und bleibt dort, auch wenn du den Podcast selbst löschst. Ein gelöschter Podcast landet im [Papierkorb](./papierkorb.md).

Willst du einen eigenen Text vorlesen lassen statt eines Gesprächs, nimm [Grünerator Voice](../guides/einsteigerinnen/text-vertonen.mdx).
