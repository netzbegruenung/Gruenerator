# Sharepics: alle Varianten auf einen Blick

Der Sharepic-Creator macht aus einem kurzen Auftrag ein Einzelbild oder ein Karussell im passenden Grünen-Design. Welches Design verwendet wird, richtet sich nach deinem Land im Grünerator.

Der Creator kennt genau diese 15 Formen: **Einzelbild, Zitat, Karussell, Interview, Infografik, Diagramm, Große Zahl, Rechnung, Termine, Schlagzeile, Bingo, Vergleich, Faktencheck, Faktenbild** und **Veranstaltung**. Du kannst eine Form ausdrücklich nennen oder den Grünerator eine passende auswählen lassen.

:::warning[Experimentelles Feature]
Prüfe Texte, Zahlen, Zitate und Quellen vor jeder Veröffentlichung. Die Aussagen und Daten in den folgenden Bildern sind erfundene Beispiele.
:::

## Deutschland

Nur im deutschen Design gibt es außerdem:

- die acht Farben **Tanne, Dunkeltanne, Grasgrün, Mint, Hellgrau, Creme, Aubergine** und **Weiß**
- einen randlos geteilten **Vergleich** mit „VS“ zwischen zwei Spalten
- eine **Liste im Kasten**, bei der Kennzahlen als Textmarker hervorgehoben werden
- ein farbiges **Kopfband** über Karten und eine große, blasse **Sonnenblume** auf Farbflächen
- besonders lange Zitate und Textseiten, etwa für Interviews

## Österreich

Österreichische Sharepics verwenden **Gotham Narrow** für klare, kompakte Überschriften und **Vollkorn** für gelbe Akzente. Dazu kommen die österreichische Farbwelt und der typische handgezeichnete Weiter-Pfeil.

## Formen in Deutschland und Österreich

Die 15 Formen stehen in beiden Ländern zur Verfügung:

| Form          | Was entsteht                                                                    |
| ------------- | ------------------------------------------------------------------------------- |
| Einzelbild    | eine große Aussage auf einer Farbfläche oder einem Foto                         |
| Zitat         | eine Aussage mit Name, Funktion und optionaler Quelle                           |
| Karussell     | drei bis acht zusammenhängende Slides                                           |
| Interview     | Cover-Zitat, danach Slides mit Frage und Antwort und ein Schluss                |
| Infografik    | kurze Informationen als Raster, Ablauf, Mengenvergleich, Anteil oder große Zahl |
| Diagramm      | Werte als Balken, Balken quer, Linie, Kreis oder Donut                          |
| Große Zahl    | eine Kennzahl über Text, als Riesenzahl oder im Countdown-Kreis                 |
| Rechnung      | Zahlen oder Begriffe, die Schritt für Schritt verrechnet werden                 |
| Termine       | zwei bis sechs Termine gemeinsam auf einer Slide                                |
| Schlagzeile   | eine Meldung als Zeitungsausriss oder Karte; dazu gehört auch „Good News“       |
| Bingo         | neun oder 16 kurze Aussagen in einem Raster                                     |
| Vergleich     | zwei Positionen oder Pläne direkt gegenübergestellt                             |
| Faktencheck   | bis zu drei Paare aus Mythos und Fakt                                           |
| Faktenbild    | eine Zahl oder ein Diagramm vor einem eigens KI-generierten Hintergrundmotiv    |
| Veranstaltung | ein einzelner Termin mit Datum, Uhrzeit und Ort                                 |

## Gemeinsame Gestaltungsmöglichkeiten

Die Formen lassen sich mit diesen Bausteinen kombinieren:

| Bereich              | Varianten                                                                                        |
| -------------------- | ------------------------------------------------------------------------------------------------ |
| Ausgabe              | eine Slide; Karussell mit drei bis acht Slides                                                   |
| Format               | 4:5; 3:4                                                                                         |
| Hintergrund          | Farbfläche; Foto über die ganze Fläche; Foto oben; Foto unten                                    |
| Foto in der Slide    | Streifen oben; Streifen unten; Karte; Kreis; freigestellte Person                                |
| Fotofilter           | grün eingefärbt; Graustufen; Original                                                            |
| Text                 | Dachzeile; mehrzeilige Überschrift; kurzer Text; Absatz; Zitat; Frage und Antwort; Button        |
| Hervorhebungen       | farbiges Schlüsselwort; handgezeichneter Kreis; handgezeichnete Unterstreichung                  |
| Listen               | Punkte; Ziffern; Pfeile; Haken; Emojis; Iconliste                                                |
| Daten und Fakten     | fünf Diagrammarten im Feinschliff; Vergleich; Faktencheck; Rechnung; Termine; Bingo; Schlagzeile |
| Große Zahl           | Zahl über Text; Riesenzahl; Countdown                                                            |
| Infografik           | Raster; Ablauf; Mengen; Anteil; große Zahl                                                       |
| Karussell-Navigation | keine; Pfeil; Pfeil und Punkte; Pfeil und Seitenzahl; nur Seitenzahl                             |
| Nummerierung         | aus; große Ziffer; Ziffer im Hintergrund                                                         |
| Schluss-Slide        | Ausruf; Kernsatz; Petition                                                                       |

Im vollständigen Canvas-Editor kannst du bei Diagrammen zusätzlich die Art **Fläche** auswählen. Außerdem kann der Creator Datum, Uhrzeit, Ort, Störer und Quellenangaben ergänzen.

Alle sechs Beispiele auf dieser Seite wurden vollständig mit dem aktuellen Sharepic-Renderer des Grünerators erzeugt.
