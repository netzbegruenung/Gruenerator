# Wie wandle ich einen bestehenden Agent um?

Eigene Grünerator-Agents, die du bereits angelegt hast, kannst du weiter verwenden. Für neue Aufgaben legst du ein Rezept oder Projekt an. Willst du die Anleitung eines bisherigen Agents übernehmen, dauert die Umwandlung nur wenige Minuten. Der ursprüngliche Agent bleibt dabei erhalten.

## So geht’s

1. Öffne die bisherige Übersicht **Grüneratoren** unter [gruenerator.eu/grueneratoren](https://gruenerator.eu/grueneratoren). Wähle deinen Agent unter **Agents laufen aus** oder öffne seine Bearbeitungsseite und klicke auf **Umwandeln**. In der App findest du **In Rezept oder Projekt umwandeln** im Editor deines Agents.
2. Wähle **Rezept**, wenn du vor allem eine wiederverwendbare Schreibanleitung brauchst. Wähle **Projekt**, wenn auch Notebooks, Projektanweisungen oder wiederkehrende Aufgaben dazugehören.
3. Lies unter **Was passiert**, was der Grünerator bei deiner Auswahl übernimmt. Wechsel zwischen den beiden Zielen, um die Angaben zu vergleichen.
4. Bestätige mit **In Rezept umwandeln** oder **In Projekt umwandeln**. Öffne den Nachfolger und probiere ihn mit einer typischen Anfrage aus. Später kommst du über **Nachfolger ansehen** wieder dorthin.

![Umwandlungsdialog mit den Zielen Rezept und Projekt. Für Projekt nennt die Vorschau Anweisungen, ein Notebook und eine wiederkehrende Aufgabe als übernommene Inhalte.](/img/guides/projekte/agent-umwandeln.webp)

## Was kommt mit?

|                                           | Rezept                                                               | Projekt                                                                                        |
| ----------------------------------------- | -------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| **Anleitung**                             | Die Rolle wird zur Rezept-Anleitung.                                 | Die Rolle wird zur Projektanweisung. Eine längere Rolle kommt als eigenes Rezept ins Projekt.  |
| **Notebooks und wiederkehrende Aufgaben** | Sie bleiben beim bisherigen Agent.                                   | Notebooks werden ins Projekt geteilt. Eigene wiederkehrende Aufgaben können dort weiterlaufen. |
| **Freigaben an Projekte**                 | Der Grünerator versucht, das Rezept in dieselben Projekte zu teilen. | Das neue Projekt startest du allein. Weitere Personen kannst du danach einladen.               |

Prüfe die Angaben im Dialog besonders bei öffentlichen Agents und Agents mit fester Werkzeug- oder Modellwahl. Eine öffentliche Listung, Begrüßung und Startfragen werden bei der Umwandlung nicht übernommen. Wenn beim Anlegen weniger mitkam als angekündigt, zeigt der Dialog, was fehlt.
